# 旅行者档案填写表

这份表格用于把您的出行偏好交给组织者的行程规划助手，规划时会严格遵守您填写的忌口与体力限制。带 ★ 的项目请务必填写，其余可以留空。填写完成后把文件原样回传即可；数据只保存在组织者本地的电脑上。

| 项目 | 您的填写 | 说明与示例 |
|---|---|---|
| ★ 称呼 |  | 例：爸爸 / 小王（档案里显示的名字） |
| ★ 忌口与过敏 |  | 有食物过敏请务必写全，例：花生、海鲜；没有请写“无” |
| 辣度 |  | 完全不吃 / 微辣 / 正常 / 无辣不欢 |
| 喜欢吃什么 |  | 例：本地特色、面食、甜食、清淡的汤菜 |
| 不吃什么 |  | 例：内脏、香菜、太油腻、生冷 |
| 行程节奏 |  | 松弛（每天 2 个点左右）/ 适中 / 紧凑（多打卡） |
| 体力与步行 |  | 每天大约能走多少路；能不能爬山、爬台阶；要不要午休 |
| 兴趣偏好 |  | 古迹 / 博物馆 / 自然山水 / 公园 / 街区市集 / 购物 / 拍照 / 夜景 / 演出，可多选、可补充 |
| 特别不喜欢 |  | 例：排队太久、早起、行程排太满、频繁换酒店 |
| 预算倾向 |  | 经济 / 舒适 / 不限；单餐人均大概多少（选填） |
| 其他要交代的 |  | 例：吃药时间、素食、晕车、带小孩（选填） |

填写中有拿不准的地方，写“不确定”或直接备注即可。填写完回传本文件。
