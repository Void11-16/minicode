**情侣出行提示**

- 户外行程（登山、古城散步）尽量排在**上午或傍晚**，中午在室内（博物馆、咖啡馆）避暑。
- 江郎山山路雨后湿滑，穿防滑鞋，登顶量力而行。

## 二、片区划分（按距离由近到远）

### 片区 A｜古城核心区（距市中心 0.4~1km，全程步行）
孔氏南宗家庙、中国儒学馆、衢州博物馆、钟楼、府山公园、水亭门历史文化街区、
侵华日军细菌战衢州展览馆、杜立特行动纪念馆

### 片区 B｜市区公园带（距市中心 2~3.2km）
世纪公园、鹿鸣公园、月亮湾公园、月亮岛（18.8km）

### 片区 C｜远郊景区（江山市方向，市区西南约 40~100km，需自驾/包车）
江郎山（约 40km）、廿八都古镇（约 90km）

> 说明：江郎山精确坐标未查到，上述距离为方位估算，实际以导航为准。

## 三、三日行程（情侣版）

### Day 1｜浪漫古城漫步（片区 A，全程步行）

| 时段 | 安排 |
|------|------|
| 上午 | **孔氏南宗家庙** → **中国儒学馆**（南孔文化，安静雅致，适合合影） |
| 中午 | 水亭门街区午餐：衢州特色「三头一掌」、搁袋饼，两人分食更划算 |
| 下午 | **衢州博物馆**（避暑）→ **钟楼** → **府山公园**（登高看老城，适合下午茶时光） |
| 傍晚 | **水亭门历史文化街区**夜景灯光，沿江散步、拍照 |
| 夜晚（可选） | 找一家古城小酒馆或咖啡馆，留一段二人时光 |

💡 当天降雨较少时段在傍晚，把夜景和散步放在这时体验最好。

### Day 2｜远郊自然日（片区 C，建议自驾/包车）

| 时段 | 安排 |
|------|------|
| 上午 | 从市区出发赴 **江郎山**（车程约 1 小时），打卡一线天、登顶赏景 |
| 中午 | 山下农家菜午餐 |
| 下午 | 前往 **廿八都古镇**（继续南行约 1 小时），逛明清古街、听方言「廿八都话」 |
| 傍晚 | 古镇晚餐 + 返程，或直接在古镇住一晚体验慢生活 |

💡 情侣提示：古镇石板巷 + 老宅灯光很适合拍情侣照；雨天巷子人少，反而更清静。
⚠️ 全天行程较满，若不想太赶，可**二选一**（推荐江郎山登高 or 廿八都漫步）。

### Day 3｜市区轻松收尾（片区 A+B）

| 时段 | 安排 |
|------|------|
| 上午 | **侵华日军细菌战衢州展览馆** → **杜立特行动纪念馆**（历史主题，情侣共同感受） |
| 中午 | 市区午餐 |
| 下午 | **鹿鸣公园 / 月亮湾公园** 沿江散步，或 **月亮岛** 观景 |
| 傍晚 | 购物采购伴手礼，返程 |

## 五、情侣出行小贴士

1. **共撑一把伞**逛古城，雨天也能成为回忆。
2. Day 1、Day 3 安排在市区步行区，**减少交通折腾**，把精力留给二人相处。
3. Day 2 若自驾，可考虑在廿八都住一晚，看星空、慢节奏，比当天往返更惬意。
4. 衢州口味偏辣（三头一掌很辣），不嗜辣的情侣点菜时记得说「微辣」。
5. 纪念馆类景点注意开放时间，尽量提前确认。
