如何读这份记录 · 采集范围与源码入口

使用一个独立会话，通过 AgentRuntime.send() 运行真实模型和注册工具。工具在隔离工作区写行程，预算续期用追踪脚本的评测式判断。正式 Web 会将追加预算请求交给用户。未采集浏览器 HTTP、模型供应商密钥或地图供应商的请求正文。本页只加载当前轮，其他轮可从目录打开。

同一份内容可能出现多次。 Context 记录传给 Provider 的内部消息和工具定义。Provider 记录 OpenAI 兼容请求体与响应原文。LLM 记录 Provider 解析后交回 Agent 的结果。Tool 是执行器的原始结果，ToolRegistry 的结果可能已经加入地点证据等包装，Session 写回的是准备带入下一轮的内容。

「请求 1」是第一次带工具模型请求，之后按模型请求编号递增。请求前的用户写入属于请求 0。流式响应原文由旁路异步采集，因此记录写入顺序可能与同次调用的解析结果交错，请用 wire 关联 HTTP 请求，用 callId / toolCallId 关联单次工具调用。上下文摘要请求仍有独立的 wire。

质量口径。 Validator 记录保存或校验时的质量报告，并在结束后独立复核最终文件。Eval 读取最终文件，按案例约束再测天数、必去项、预算与其他指标。Agent Loop 的「本轮结束」只代表运行结束。校验失败会在异常文本中保留报告，未提交的内部对象没有额外快照。
